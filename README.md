# Версия РФ на базе итоговой СНГ

Программа: 18–24 октября 2026, 7 дней. Программа, изображения, баннеры, контакты и отели взяты из текущей локальной РФ. Тестовые участники и настройки домов — из исходной поставки итоговой СНГ. Рабочие сессии, пароли и приглашения не копировались.

Аудиозадания отключены, английский для участников и гостей выключен. У организатора переключатель EN также скрыт, пока поддержка английского выключена. Код приложения общий с drakon_english; изменена только настройка названия группы. Манифест установленного приложения и шаблон Kubernetes настроены для РФ.

## Локальный запуск

```powershell
cd C:\put-drakona-server-2\drakon_rf
$env:ALLOW_LOCAL_HTTP='1'
$env:HOST='127.0.0.3'
$env:PORT='3104'
node server/server.js --password 'ВАШ_ПАРОЛЬ_ОТ_12_СИМВОЛОВ'
node server/server.js
```

Открыть http://127.0.0.3:3104/. Пароль задаётся первой командой только при настройке или смене. Для запуска используйте отдельное окно PowerShell без DATA_DIR, ASSETS_DIR и PUBLIC_ORIGIN от других приложений.

Для сервера нужны отдельные HTTPS-домен и хранилище РФ; замените заглушки в deploy/kubernetes.yaml. Новые исходные данные применяются при первом запуске с пустым хранилищем; существующее хранилище они не перезаписывают.

README-RU-EN.md описывает общие возможности движка на примере СНГ; даты, включённые языки и команды запуска для этой поставки берите из этого README. Унаследованные тесты с фиксированной программой СНГ требуют соответствующих тестовых данных.

Замена иконки доступна в «Контакты → Оформление». Требования: [Иконка приложения.md](<Иконка приложения.md>).
