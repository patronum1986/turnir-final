# drakon_english — СНГ, русский и английский

Отдельная версия на основе актуальной «Группа СНГ» от 21.09.2026. Даты программы: 24–31 октября 2026. Основные папки РФ и СНГ не менялись. Рабочие участники, пароль, сессии и персональные ссылки из старой папки не копировались: при первом запуске используются исходные тестовые данные СНГ.

## Язык участника

В режиме организатора откройте «Участники → Редактировать список».

- «Язык приложения»: русский по умолчанию, либо English.
- «Имя латиницей»: автоматически заполняется при вводе русского имени. Можно исправить; ручной вариант не перезаписывается дальнейшим вводом русского имени.
- «Банк на английском»: заполняется вручную. Если пусто, используется исходное название банка.

Участник с языком English при первом входе по персональному приглашению получает английский интерфейс. В правом верхнем углу баннера доступен переключатель RU | EN: активный язык показан обычным текстом, другой — ссылкой. Такой же переключатель есть на странице входа. Ручной выбор сохраняется для этого участника на устройстве и имеет приоритет над назначением организатора. На новом устройстве применяется назначение организатора. При очистке данных браузера ручной выбор теряется. Сведения о языке других участников в публичную выдачу не добавлялись; свой язык участник получает после входа.

## Отключение английского

«Контакты → Оформление → Поддержка английского языка».

При отключении английского язык участников и страницы входа становится русским, переключатель RU / EN для них скрывается. Переводы, язык карточек и ручные предпочтения не удаляются. При повторном включении они снова действуют. При отключении английского переключатель скрыт также у организатора; интерфейс всех ролей становится русским. Устройство офлайн узнаёт об отключении после получения обновления с сервера; уже сохранённая офлайн-копия сама по себе не обновится.

## Переводы материалов

Войдите как организатор и выберите EN в верхнем переключателе. Откройте привычную форму редактирования дня, задания, контактов, оформления, команд или участника. В EN эти формы показывают и сохраняют английский текст. В RU — русский. Над страницей показан текущий язык редактирования; кнопки администрирования остаются русскими. Выбор языка организатора сохраняется на устройстве. Перед переключением завершите сохранение текущей формы.

Правки двух языков хранятся отдельно. В форме дня доступен также текст блока «Важное». Общие настройки — даты, состав дней, изображения дней, аудио, телефоны, адреса мессенджеров и распределение команд — меняются в RU; соответствующие поля в EN заблокированы. Новых участников добавляйте в RU, затем при необходимости исправляйте английские имя и банк. Пустой перевод использует русский оригинал.

### Баннеры RU и EN

В разделе «Контакты → Оформление» главный баннер и баннер входа загружаются отдельно для выбранного языка. Выберите RU для русского изображения, EN — для английского. Размер обоих баннеров — 1400×500 px. Загрузка в EN не меняет RU и наоборот. Пока английское изображение не загружено, используется русское, включая его последующие обновления.

В EN кнопка «Использовать русский баннер» сбрасывает английский главный баннер. «Убрать баннер входа» в EN возвращает русский баннер входа; в RU убирает русский вариант. Оба варианта включены в загрузку для офлайн-режима. До авторизации доступны только выбранные баннеры входа; главный баннер требует авторизации. При отключённой поддержке английского гостям выдаётся русский баннер входа.

По согласованию переведены и внесены программа всех восьми дней, расписание, блок «Важное», контакты, примечания отелей, оформление входа, подвал, дома и сценарий жребия, названия заданий. Русские тексты и время мероприятий сохранены. Встроенный текст на баннерах и записи аудио остаются исходными. Английские баннеры можно загрузить отдельно; новые изображения в поставку не добавлены.

Переводы находятся в исходных данных server/seed и загружаются при первом запуске новой копии. В поставке нет server/data. Если запускать с уже существующим хранилищем DATA_DIR, исходные данные не заменят его содержимое: такая установка требует отдельного переноса переводов.

До входа доступно только оформление страницы входа, включая согласованные английские поля и флаг поддержки языка. Закрытые материалы и список участников требуют авторизации.

## Участники CSV

В редакторе списка есть «Выгрузить участников CSV» и «Импорт CSV». Выгрузка участников отличается от links.csv: содержит данные карточек и постоянные ID, но не персональные приглашения.

Формат: UTF-8 (BOM допустим), разделитель `;` или `,`, стандартные двойные кавычки. До 2 МБ и 2000 строк за один импорт. Заголовки:

`id;name;name_en;bank;bank_en;language;house`

Обязательна колонка `name`; для нового участника обязательно непустое имя. Язык — строго `ru` или `en`, пустой у нового участника означает `ru`. Пример находится в «Шаблон участников.csv» и сам не загружается в приложение.

| Строка файла | Результат |
| --- | --- |
| ID найден | Обновляется существующая карточка; сохраняются её ID, приглашение, фото и распределение по дому |
| ID пустой | Создаётся новый участник и новая персональная ссылка |
| ID указан, но не найден | Ошибка, импорт не применяется |
| ID повторён внутри файла | Ошибка, импорт не применяется |
| Без ID совпадают имя и банк с существующей или новой строкой | Возможный дубль, импорт не применяется до уточнения |
| Пустая ячейка обновляемой карточки | Текущее значение остаётся |
| Участника нет в CSV | Карточка остаётся |

Нельзя гарантированно сопоставить изменённое имя без ID. Для повторных загрузок сначала выгружайте текущий список с ID. Не редактируйте ID в Excel; храните эту колонку как текст. Однофамильцев не объединяем автоматически. Чтобы очистить поле, используйте карточку участника, а не пустую ячейку CSV.

Перед применением показываются добавления, обновления и ошибки. При любой ошибке весь импорт блокируется. Если после проверки список изменился, подтверждение отклоняется — нужно повторить проверку файла. Один клик подтверждения применяет весь список; повторная отправка устаревшей проверки не создаёт дополнительные карточки.

Если `name_en` заполнено, оно считается указанным вручную. Если не заполнено, для нового имени создаётся транслитерация; ранее вручную заданный вариант сохраняется. Транслитерация предназначена для отображения, это не паспортное написание. Проверьте имена при необходимости. Выгрузка экранирует начало ячеек, похожее на формулы Excel, апострофом; обратный импорт восстанавливает значение.

## Локальный запуск

Используется отдельный loopback-адрес, чтобы cookie этой копии не мешали вашим запущенным версиям на 127.0.0.1. В PowerShell:

```powershell
cd C:\put-drakona-server-2\drakon_english
$env:ALLOW_LOCAL_HTTP='1'
$env:HOST='127.0.0.2'
$env:PORT='3103'
node server/server.js --password 'ВАШ_НОВЫЙ_ПАРОЛЬ_ОТ_12_СИМВОЛОВ'
node server/server.js
```

Команда с паролем выполняется только для задания или смены пароля; следующими запусками достаточно последней команды с указанными переменными окружения. Открыть http://127.0.0.2:3103/. Здесь пароль не предустановлен. После остановки сервера параметры среды в текущем PowerShell сохраняются; для другой версии используйте отдельное окно.

## Размещение и проверки

Нужны отдельный HTTPS-домен и отдельное состояние. Namespace шаблона — drakon-english, домен-заглушка — english.example.invalid. Перед установкой заменить все заглушки. Нельзя публиковать как подпапку старого сайта или использовать общий PVC с основной СНГ.

Унаследованы согласованные решения от 21.09: нет встроенных лимитов попыток входа; одна пишущая реплика; закрытые API; офлайн-копии; /api/ready проверяет данные и хранилища. Прежние ограничения очистки фоновых загрузок и параллельного редактирования основного контента специально не перерабатывались. Для CSV добавлена отдельная проверка актуальности списка перед подтверждением.

`npm test` — серверные проверки; `npm run test:browser` — английский, CSV, переключатель поддержки, офлайн и прежние браузерные сценарии. Для браузерных тестов нужны Playwright и Microsoft Edge. Рабочие данные в тестах не используются. Реальный Kubernetes и физические iPhone/Android требуют отдельной приёмки.

## Вход организатора из приложения

Удерживайте главный баннер 1,5 секунды: появится системный запрос пароля браузера. Отмена, пустой ввод, неверный пароль или отсутствие сети оставляют текущую страницу открытой. После успешного входа сохраняются выбранные раздел и день. Удержание переключателя RU | EN не вызывает запрос пароля. Стандартный браузерный prompt показывает вводимый текст без маскировки; пароль передаётся серверу для проверки, локально не сохраняется. Вход через форму на странице входа также доступен.

## Дом при импорте CSV

Необязательная колонка `house` содержит название дома из раздела «Команды»: русское или английское. Регистр и лишние пробелы не влияют на сопоставление. Неизвестное или неоднозначное название блокирует весь импорт до исправления. До подтверждения рядом с участником показан назначаемый дом.

Пустая ячейка или отсутствие колонки сохраняют текущий дом; новый участник остаётся без назначения. Импорт не отмечает жребий пройденным и не меняет режим команд. Для очистки назначения используйте карточку участника в RU.

Пример:

```csv
id;name;name_en;bank;bank_en;language;house
;Иван Петров;Ivan Petrov;Банк А;Bank A;ru;Дом Нефритового Дракона
```

При выгрузке CSV `house` заполняется текущим русским названием дома. Старые CSV без этой колонки продолжают работать. Для обновления существующих карточек сохраняйте их id из выгрузки.

После изменения списка участников, названий домов или назначений подтверждение старой проверки отклоняется. Импорт сохраняет карточки и назначения через журнал восстановления: прерванная запись завершается при следующем запуске, персональные приглашения существующих участников сохраняются. Рабочий файл .csv-import.json, если существует, относится к DATA_DIR и должен входить в резервную копию вместе с остальными данными.
