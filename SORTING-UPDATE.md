# Обновление сортировки участников — РФ v5

Изменена только сортировка списка участников и необходимое для неё сохранение/проверка настроек.

В режиме «Редактировать список» организатор выбирает: по ФИО; по Домам, затем по ФИО; ручной порядок. Вручную строки перемещаются кнопками ↑ ↓ при пустом поиске. Новые участники идут в конец ручного списка. Галочка «Показывать текущего участника первым» действует для участников во всех режимах; в редакторе закрепление выключено, чтобы не мешать перестановке. Пользовательских настроек сортировки нет.

При поиске закрепляется только участник, соответствующий запросу. По умолчанию все режимы показывают единый список. Галочка «Показывать команды отдельными блоками» доступна только организатору при сортировке по Домам. При её включении собственная строка (если включено закрепление) вынесена сверху без дублирования. Порядок Домов соответствует их списку в настройках, нераспределённые идут в конце. При выключенных Домах или незавершённом раскрытии через жребий участники видят алфавитный список, чтобы не раскрывать скрытое распределение.

Настройки: peopleSort в рабочем site.json (mode, selfFirst, groupHouses, order из ID). До первого изменения: по ФИО, закрепление и блоки выключены. В ранее сохранённых настройках отсутствие groupHouses означает выключенные блоки. Seed и рабочие данные не заменяются. Ручной порядок сохраняется при переключении режимов. Доставка настроек на другие устройства использует существующее обновление приложения: перезагрузка или штатный опрос сервера.
